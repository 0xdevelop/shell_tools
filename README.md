# 1. usaged
## 1.1. imagemagick_covert_icons.sh
### 1.1.1. 一键调用命令
```
wget --no-check-certificate https://raw.githubusercontent.com/0xdevelop/shell_tools/master/imagemagick_covert_icons.sh && chmod a+x ./imagemagick_covert_icons.sh && ./imagemagick_covert_icons.sh
```
### 1.1.2. 支持自定义 Logo 路径
```
wget --no-check-certificate https://raw.githubusercontent.com/0xdevelop/shell_tools/master/imagemagick_covert_icons.sh && chmod a+x ./imagemagick_covert_icons.sh && ./imagemagick_covert_icons.sh ./my_logo.png
```
